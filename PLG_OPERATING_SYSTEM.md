# PartsLink Global Operating System

## Mission
Capture every customer request, organize the information, identify the correct parts, and turn that request into a completed sale with the fewest possible steps.

## Core Principles
1. Capture first. Organize later.
2. Every screen answers one question.
3. Never ask twice.
4. Always show the next practical step.
5. PLG remembers so the user does not have to.
6. Practical before powerful.
7. One thought per screen.
8. A feature is not finished until it is useful in real work.

## Workflow
Customer Request → Customer → Registry → Job → Parts Workspace → Quote → Invoice → Completed
