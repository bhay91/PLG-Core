PLG Core v0.16 - Administration and Document Templates

Adds:
- Administration area
- Document Templates page
- Upload PDF master corporate template
- Automatic version numbering
- Active/inactive template versions
- Preview PDF in browser
- Restore an older version
- Seeds the approved PLG Master Corporate PDF as version 1

Install:
1. Stop PLG Core.
2. Run: python3 install_v016.py
3. Restart PLG Core.
4. Open Administration > Document Templates.
