PLG Core v0.9 — Supplier Selection

What this update adds:
- Clean requested-part and matched-OEM display
- Removes Diagram / Group / Callout from the working screen
- OEM price becomes an automatic selectable source
- Multiple sources per part: OEM, aftermarket, or used
- Manual supplier entry for phone quotes such as Costex
- One-click source selection for each part
- Mixed OEM and aftermarket selections in the same job
- Quote readiness count
- Existing OEM and supplier information is migrated automatically

Install:
1. Stop PLG Core with Ctrl+C.
2. Extract this ZIP.
3. Open a terminal in the extracted folder.
4. Run: python3 install_v09.py
5. Restart PLG Core.

This update does not yet generate the PDF quote. It builds and tests the supplier-selection foundation first.
