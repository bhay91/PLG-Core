PLG Core v0.10 — Supplier Lists

Adds:
- Saved supplier directory with type-or-select field
- Brand suggestions that grow from saved source records
- Reman source type
- Supplier part number defaults to OEM number when left blank
- Availability dropdown: In Stock, Out of Stock, Back Order
- Lead-time dropdown: 1-3 Days, 5 Days, 2 Weeks, 1 Month, Back Order

Install:
1. Stop PLG Core with Ctrl+C.
2. Extract this ZIP.
3. Open a terminal in the extracted folder.
4. Run: python3 install_v010.py
5. Restart PLG Core with ./run.sh.
