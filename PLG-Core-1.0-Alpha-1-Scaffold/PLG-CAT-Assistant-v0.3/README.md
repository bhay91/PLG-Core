# PLG CAT Assistant v0.3

This version connects directly to PLG Core.

Workflow:
1. Open a job in PLG Core.
2. Click Verify in CAT on the requested part.
3. CAT Parts opens in a new tab.
4. Open the extension.
5. Click Load machine PIN.
6. Navigate to the correct diagram.
7. Enter the OEM part number and description.
8. Click Capture to PLG Job.
9. Refresh the PLG job page.

Install:
- Remove the old temporary extension.
- Load this version's manifest.json from about:debugging.
