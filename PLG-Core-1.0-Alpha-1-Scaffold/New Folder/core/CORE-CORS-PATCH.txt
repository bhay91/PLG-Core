# PLG Core v0.3.1 hotfix

In app.py, replace the existing CORS middleware block with:

app.add_middleware(
    CORSMiddleware,
    allow_origins=[
        "http://127.0.0.1:8000",
        "http://localhost:8000",
    ],
    allow_origin_regex=r"^moz-extension://.*$",
    allow_credentials=False,
    allow_methods=["*"],
    allow_headers=["*"],
)

This allows the temporary Firefox extension's changing moz-extension:// UUID
to call the local PLG API.
