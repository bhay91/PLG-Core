# PLG CAT Assistant v0.2

This version adds OEM terminology expansion.

## Install temporarily

1. Extract the ZIP.
2. Open Firefox.
3. Go to `about:debugging#/runtime/this-firefox`.
4. Remove the old PLG CAT Assistant.
5. Click **Load Temporary Add-on...**
6. Select this folder's `manifest.json`.
7. Reload the CAT Parts tab.

## Test

1. Enter `FDP15598` and click **Add equipment**.
2. Select the 420D result if CAT asks.
3. Enter `accelerator cable`.
4. Click **Build OEM search terms**.
5. Start with `Cable Assembly (Governor Control)`.
6. Use **Search next term** to test the alternatives.

This extension is human-assisted and does not choose or purchase parts for you.
