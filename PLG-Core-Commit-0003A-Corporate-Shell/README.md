# PLG Commit 0003A — Corporate Shell

This is the first visible implementation of the approved PartsLink Global UI.

## Included

- PartsLink Global logo on every page
- White corporate interface
- PLG blue and navy branding
- Slimmer left navigation
- Blue active-page indicator
- New sticky header
- Search field placeholder
- Brandon administrator identity
- Optimized page width
- Modern cards, forms, tables, buttons, spacing, and typography
- Existing routes and business logic preserved
- Automatic backup and rollback

## Install

Stop PLG, then run:

```bash
python3 install_commit_0003A.py
```

Restart:

```bash
cd ~/Desktop/PLG-Core
source .venv/bin/activate
./run.sh
```

Open:

`http://127.0.0.1:8000`

## Test

Check Dashboard, Jobs, a Job Details page, Connectors, and Administration.

Do not commit until the layout has been reviewed.
