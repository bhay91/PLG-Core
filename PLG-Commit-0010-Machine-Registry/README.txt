PLG Commit 0010 — Machine Registry Foundation

INSTALL
1. Extract this ZIP.
2. Copy install_commit_0010.py into your PLG-Core project folder.
3. Open the VS Code terminal in PLG-Core.
4. Run:

   python3 install_commit_0010.py

5. Start PLG:

   ./run.sh

6. Test:

   http://127.0.0.1:8000/machines

The installer creates a timestamped backup before changing files.
