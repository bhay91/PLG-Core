# PLG Commit 0007A — Quotes & Suppliers Navigation

Adds:
- Clickable Quotes sidebar link
- Quote Register with search and PDF actions
- Clickable Suppliers sidebar link
- Supplier Register with usage, jobs, selected lines, spend, and recent activity

Install:
```bash
python3 install_commit_0007A.py
```

Restart PLG, then open:
- http://127.0.0.1:8000/quotes
- http://127.0.0.1:8000/suppliers
