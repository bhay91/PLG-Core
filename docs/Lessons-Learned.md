# PLG Lessons Learned

## LL-001 — Small Commits Are Safer

Small, focused commits make it easier to verify, understand, and recover work.

## LL-002 — Request Output Before Assuming

When the current code, database, or server state is uncertain, inspect it before changing anything.

## LL-003 — Job-Level Data for Job-Level Work

Information representing work performed belongs to the Job rather than one Quote revision.

## LL-004 — Reminders Should Guide, Not Obstruct

PLG should help prevent mistakes without creating unnecessary friction.

## LL-005 — Generated Documents Are Business Data

Customer PDFs and Parts Order Sheets should not be mixed into source-code commits unless intentionally versioned.

## LL-006 — Documentation Must Be Permanent

Important product decisions must be saved in the repository rather than relying only on conversation history.
